# مركز بساتم لصيانة السيارات

موقع تعريفي تسويقي + نظام إلكتروني لإدارة المركز، باللغة العربية.

## ماذا يحتوي؟

### الموقع التعريفي (`/`)
- واجهة بتصميم داكن وتوهج برتقالي، ورسم سيارة متحرك بخط «فحص».
- الخدمات، وكيف نعمل، ولماذا بساتم، وفريق العمل (يُدار من النظام).
- نموذج «احجز موعدك» تصل طلباته إلى النظام مباشرة.
- بيانات التواصل (الهاتف، واتساب، العنوان، الخريطة، أوقات العمل) تُعدّل من الإعدادات.

### النظام (`/login`)
| الصفحة | الوظيفة |
|---|---|
| الرئيسية | ملخص اليوم: إيرادات اليوم، صافي الشهر، المستحقات، السيارات في الورشة، رسم بياني |
| اتفاقيات العمل | استلام السيارة: العميل، السيارة، الشكوى، التشخيص، الأعمال التقديرية، العربون، الشروط، طباعة للتوقيع، ثم «تحويل إلى فاتورة» بنقرة |
| الفواتير | فاتورة بالبنود (خدمات/قطع)، خصم، ضريبة 15% اختيارية مع رمز QR (المرحلة الأولى للفوترة الإلكترونية)، دفعات جزئية، طباعة/PDF، إرسال واتساب، إلغاء (للمدير) |
| الإيرادات والمصروفات | دفعات الفواتير تُسجّل تلقائياً، وتسجيل المصروفات بالتصنيف، وصافي الربح الشهري والمقارنة بالشهر السابق |
| طلبات الحجز | طلبات الموقع مع اتصال وواتساب ومتابعة الحالة |
| فريق العمل | المهندسون والفنيون الظاهرون في الموقع |
| المستخدمون والصلاحيات | المدير يملك كل شيء، ويمنح الموظف: إصدار الفواتير / اتفاقيات العمل / الإيرادات والمصروفات / طلبات الحجز |
| الإعدادات | بيانات المركز، الرقم الضريبي، التواصل، تذييل الفاتورة، شروط الاتفاقية |

## التصميم
- مبني على **نظام تصميم ركين** (الرموز الدلالية، الزوايا، الظلال، الزاوية المميزة، الوضع الداكن) بهوية جديدة: «جمر» برتقالي على «جرافيت».
- الخطوط: **IBM Plex Sans Arabic** للنظام (من ركين) و**Thmanyah Sans** للعناوين التسويقية (من موقع السيرة الذاتية).
- حركات موقع السيرة الذاتية: الظهور التدريجي، والتوهج الذي يتبع المؤشر، والعدّاد.

## التشغيل محلياً
```bash
npm install
cp .env.example .env.local   # ضع رابط قاعدة البيانات
npm run db:migrate
npm run dev
```
افتح `http://localhost:3000/setup` لإنشاء حساب المدير لأول مرة.

## النشر على Vercel
1. اربط المستودع بمشروع جديد في Vercel.
2. أضف قاعدة بيانات Postgres من Marketplace (مثل Neon)؛ تُضاف `DATABASE_URL` تلقائياً.
3. أمر البناء `vercel-build` يشغّل الترحيل ثم يبني الموقع.
4. افتح `/setup` وأنشئ حساب المدير، ثم أكمل «الإعدادات».

## الفحوص
```bash
npm run lint && npm run typecheck && npm test && npm run build
```

## ملاحظات تقنية
- Next.js 16 (App Router) + Tailwind 4 + Drizzle ORM + PostgreSQL.
- المبالغ تُحفظ بالهللة (أعداد صحيحة) لتجنّب أخطاء الكسور.
- كلمات المرور Argon2id، وجلسات في قاعدة البيانات بملف تعريف HttpOnly، وحد لمحاولات الدخول.
- كل إجراء على الخادم يتحقق من الجلسة والصلاحية بنفسه.
